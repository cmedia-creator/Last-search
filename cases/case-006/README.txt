CASE006 再構築版 / ユーザー命令型追跡

流れ
1. 「探しますか？」検索ボックス
2. 「探す」に関連する入力以外 → TOPへ戻る
3. 探索系入力 → 防犯カメラ追跡開始
4. 画像1 → 画像2 → 画像3/4追加
5. 画像5は一旦エラー表示
6. ゲート1〜3通過 → 火災報知器へアクセス
7. ネット接続領域を発見 → 画像5表示
8. 7秒後ブラックアウト
9. 追跡可能領域から離脱 → 再検索2回失敗
10. 追跡中止 → 「久我あきら　死亡」
11. 7秒後TOPへ戻る

画像は既存CASE006の5枚をそのまま同梱しています。
GitHubでは cases/case-006/ をこのフォルダで丸ごと差し替えてください。


入力判定追加:
「探す」系だけでなく、「探しますか？」への自然な肯定・依頼も探索開始扱いです。
例: はい / うん / お願い / お願いします / 頼む / よろしく / OK / YES / please


更新:
- 検索ボタンを小型化。スマホでも全幅ボタンにしない。
- 5枚目表示後のブラックアウトを廃止。
- 「追跡可能領域から離脱」以降は、同じ追跡画面下部に状態行を追加して進行。
- 再検索→失敗→再検索→失敗→追跡中止→久我あきら 死亡、まで同一画面内で表示。
