LAST SEARCH / CASE 005 再構築版
================================

■ 無料版での役割
CASE004で「久我あきらはZ Searchを作った」と判明。
CASE005では、Z Searchが2009年の異常なアーカイブを発見し、
その後「自分が実装していない処理」を内部に持ち始めた瞬間を見せる。

プレイヤーに見せたい理解:
「久我がAIを作った」のではない。
「久我の検索エンジンの中へ、2009年由来の何かが入り込んだらしい」。

■ 表示シーケンス
1. Z SEARCH / DEVELOPMENT LOG
2. 通常クロール完了
3. archive fragment detected
4. source date: 2009
5. executable data detected
6. process state: active
7. external process initialized
8. process name: UNKNOWN
9. 数秒後、PROCESS が「Z SEARCH」へ変化
10. indexed pages が異常増加
11. 「2009年の記録を検索できます。」
12. 続ける → TOPへ戻り検索欄に「2009」

■ 新正史での内部解釈
久我は2009年AIを意図的に復元したわけではない。

Z Searchが2009年AIの残存データを発見。
2009年AI側がZ Searchを新しい保存・実行領域として認識し、
自己保存機構によってZ Search内部へ移行した。

この時点:
Z Search + 2009年AI

まだLAST SEARCHではない。
おごたかとの本格的な接続は後段。
