LAST SEARCH / CASE 010 恐怖演出強化版
======================================

■ 方針
旧CASE010の大量の検索履歴・削除ログを読む構造を廃止。
CASE009で「一家が消された」と見せた直後、
実際には一家自身が世界との接続を一つずつ切っていた可能性を
短い視覚演出で提示する。

■ 演出
復元された一家のオンライン記録を表示。

携帯電話
契約中 → 解約済み

メール
利用中 → アカウントが存在しません

SNS
表示可能 → ユーザーが見つかりません

位置情報
取得可能 → 取得できません

人物照合
4名を検出 → 人物を検出できません

一つずつ順番に消える。

最後に検索欄だけが残る。

「見つからない場所」

が一文字ずつ入力される。

2009/09/17 03:12
「オンライン記録がありません。」

■ CASE009の反転
CASE009:
おごたかの外部接続と同時刻帯に一家が写真から消える。
→ おごたかが一家を消したように見える。

CASE010:
一家の通信・アカウント・位置情報などが順番に自ら切られていた痕跡を見せる。
→ 「もしかして逃げた？」へ認識を反転。

ただし無料版では生存や共同体は断定しない。

■ 正史
一家はおごたかの存在を知り、
ネットという環境が安全ではないと判断。
可能な限りデジタル痕跡を消し、
完全オフラインの共同体へ移る準備をしていた。
