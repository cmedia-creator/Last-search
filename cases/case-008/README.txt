3. どちらでも以下を順に表示

4. 「捜査記録に介入する」ボタン
5. CODENAME：OGOTAKA
6. ACCESS大量表示

9. 「異常アクセスを検知しました。データの保護を行います」
10. 2件の記録を表示

13. 大量コード表示
14. 全コードが ERROR に置換
